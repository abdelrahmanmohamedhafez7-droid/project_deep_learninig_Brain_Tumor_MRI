MODEL SETUP
===========

The supplied GitHub repository does NOT currently contain the trained .keras model artifacts.
The original notebook says that these files are generated after training:

    vgg16_model_final.keras
    cnn_model_final.keras
    best_cnn.keras

This application uses:

    models/vgg16_model_final.keras

To activate real inference:
1. Take the trained `vgg16_model_final.keras` generated by your notebook.
2. Copy it into this exact folder:
       models/vgg16_model_final.keras
3. Run:
       streamlit run app.py

The application already matches the original VGG16 inference preprocessing:
- RGB
- resize to 128 x 128
- divide pixel values by 255

Do NOT use a different preprocessing pipeline with the current trained model.
